Cómo cargar documentos

  1. Entrá a Documentos y elegí Subir PDF.
  2. Arrastrá los archivos al recuadro o hacé clic para buscarlos.
  3. Seleccioná solo archivos PDF de hasta {{ max_mb|default(30) }} MB cada uno.
  4. Presioná Subir y analizar documentos.
  5. Esperá a que termine el análisis y abrí el documento para revisar el resultado.

Para facturas multipágina, el sistema conserva las hojas diferentes y evita contar copias marcadas como duplicado.

Cómo configurar y usar la IA

  1. Entrá a Ajustes y abrí Proveedor de Inteligencia Artificial.
  2. Elegí el proveedor, pegá tu API key y verificá la URL base.
  3. Escribí el modelo o usá Buscar modelos si el proveedor lo permite.
  4. Usá temperatura 0.0 para facturas y tablas: prioriza respuestas consistentes.
  5. Guardá la configuración y luego cargá un PDF. Para un documento anterior, usá Reprocesar.

La IA complementa las reglas y ayuda con descripciones, ítems y campos variables. Siempre revisá importes y datos sensibles antes de exportar.

Qué revisar antes de descargar

Detalle: emisor, receptor, fecha, comprobante e impuestos.

Ítems: códigos, descripciones, cantidades, precios e importes.

Resumen: total real de la factura y conceptos detectados.
