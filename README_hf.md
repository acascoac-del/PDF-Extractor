# PDF Extractor - Extraccion Inteligente

Converti facturas, remitos, presupuestos y contratos PDF a Excel y Word con datos estructurados.

## Caracteristicas

- Facturas AFIP: CUIT, CAE, tipo A/B/C, items, totales
- Tablas: reconstruccion de filas y columnas
- Contratos: conversion a Word con formato
- Motor hibrido: reglas + IA (OpenAI, Groq, etc.)
- Exportacion: Excel, Word, CSV, JSON

## Uso gratuito

3 PDFs por mes gratis. Suscribite por $5 USD/mes para uso ilimitado.

## Como funciona

1. Subi un PDF
2. El sistema detecta el tipo de documento
3. Extrae los campos automaticamente
4. Descarga en Excel, Word, CSV o JSON
